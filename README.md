# Excel Training – SRMU Lucknow

##  Overview  
This repository contains materials, exercises, and resources related to Excel Training conducted at Shri Ramswaroop Memorial University (SRMU), Lucknow.  
The training helps students learn Microsoft Excel from basic to advanced level.

---

## Objectives  
- Understand Excel interface and basic operations  
- Learn formulas and functions  
- Perform data cleaning and formatting  
- Create charts and visualizations  
- Work with Pivot Tables and dashboards  
- Improve productivity using shortcuts  

---

## Topics Covered  

### Basic Excel  
- Introduction to Excel  
- Workbook & Worksheet  
- Data Entry and Formatting  

### Formulas & Functions  
- SUM, AVERAGE, COUNT  
- IF, AND, OR  
- VLOOKUP, HLOOKUP, XLOOKUP  

### Data Handling  
- Sorting and Filtering  
- Data Validation  
- Conditional Formatting  

### Advanced Excel  
- Pivot Tables  
- Charts and Graphs  
- Dashboard Creation
